# Nexora Product Roadmap (ROADMAP.md)

## Phase 1: Foundation (Completed)
- Clean monorepo architecture and typed data models
- Precision Atlas design system (dark/light themes, zero-pill discipline)
- Unit-tested logic engines (Classification, Compatibility, Readiness, Search, MCP)
- High-fidelity seed repositories across all major technical domains

## Phase 2: Live Ingestion & Intelligence (Completed)
- Official GitHub API client with rate-limit tracking
- Ingestion console with on-demand GitHub repository classification
- Compatibility intelligence engine evaluating target stacks
- Evidence-backed discovery relationships graph

## Phase 3: Personal & Collaborative Workspaces (Completed)
- Custom collections with notes, tags, and JSON/CSV export
- Multi-repository side-by-side comparison workspace (up to 4 repositories)
- Watchlist subscriptions and activity notification center
- Target environment preferences configuration

## Phase 4: Agent-Native Gateway & Protocols (Completed)
- Real Model Context Protocol (MCP) server at `/api/v1/mcp`
- Interactive MCP sandbox and JSON-RPC 2.0 tool execution
- REST API v1 endpoints with OpenAPI conventions
- Scoped API key generation and management

## Phase 5: Future Enhancements (Planned)
- Package registry adapters (npm, PyPI, crates.io)
- GitHub webhooks for real-time upstream push ingestion
- Multi-tenant enterprise team collections with role-based access control (RBAC)
- Fine-grained semantic embeddings via pgvector for hybrid text-vector queries
